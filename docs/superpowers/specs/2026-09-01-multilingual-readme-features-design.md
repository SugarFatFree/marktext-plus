# 多语言 README 功能表同步设计

## 目标

将英文 `README.md` 当前四组功能表同步到 `docs/i18n/` 下的 11 份翻译 README，使各语言版本准确反映 v1.5.6/v1.5.7 周期已经实现的编辑、渲染、文件输出和轻量性能能力。

## 范围

- 修改 11 份 `docs/i18n/README_*.md`。
- 保留各文件原有语言、标题、链接、主题截图和已完成的横向对比章节。
- 将旧的 8 行功能表替换为四组表：Editing/Rendering/Files & Output/Built to stay light 的等义翻译。
- 更新 `docs/v1.5.7/PRD_需求文档.md` 中 FEAT-084 的状态和验证记录。
- 新增 `docs/v1.5.7/release-notes.md`，按主题精简记录本版本已完成内容。

不在范围内：

- 不修改 Flutter 运行时代码。
- 不重做 README 生成系统。
- 不发布 v1.5.7；v1.5.6 已于 2026-09-01 发布。
- 不在本机执行完整构建或打包。

## 实现方案

以英文 README 的四组表为内容事实源，按语言逐份人工翻译。每份翻译保持以下结构和信息完整：

1. 三种编辑模式、预览内编辑、命令面板与 `/` 菜单、表格编辑、块移动、查找替换、粘贴链接、表格整理、图片。
2. 22 种 Mermaid、数学公式、CommonMark/GFM、8 个主题、12 种界面语言。
3. HTML/PDF/Word 导出、编码识别、文件树、外部文件变更监听、原子保存、自定义快捷键。
4. 无内嵌浏览器、22 个直接依赖、大文件性能测试、测试数量。

对于技术名称、命令、文件扩展名和库名保留原文；不把尚有已知限制的 HTML 数学公式外链描述成完全离线。

## 数据流与验证

- 翻译前从英文 README 提取功能事实，并检查 11 份文件的旧功能表边界。
- 替换后使用项目自己的 `MarkdownParser` 与 `ExportService` 解析全部 12 份 README，检查无损坏字符、四组表均存在且关键条目未丢失。
- 执行 `flutter test` 和 `dart analyze --fatal-infos lib test`。
- 仅在验证通过后提交并推送 `dev`；不创建版本 tag。

## 文档记录

FEAT-084 从“部分完成”改为“已完成”，说明 11 份翻译已同时包含横向对比表和四组最新功能表，并记录解析器/HTML 导出验证结果。`release-notes.md` 只记录面向用户的实际变化，内部同步工作以文档维护项简短说明。

## 风险与处理

- 翻译内容可能造成事实漂移：统一以英文表和代码已验证能力为准。
- RTL 阿拉伯语表格可能出现排版问题：保持 Markdown 表格列数一致，验证解析结果。
- README 中的测试数量可能随代码变化：使用当前已通过的测试数量，并在验证后更新。
