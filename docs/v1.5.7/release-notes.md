# MarkText Plus v1.5.7

> 开发中的版本说明。v1.5.7 尚未发布，实际发布日期和版本号将在发布日按流程更新。

## Added

- 分屏编辑时源码区和预览区双向跟随滚动，并抑制程序化滚动造成的回环。
- 导出过程中显示进行中状态，完成后显示输出路径；PDF 排版移出主 isolate，窗口保持响应。

## Performance

- 大文档预览复用已解析的块、代码高亮和表格单元格结果，减少重复构建。
- 源码行号按真实软换行布局定位，长行和大文件滚动时不再错位。

## Markdown

- 修复折行链接引用定义、列表 Tab 缩进、列表缩进漂移和嵌套解析清空链接定义的问题。
- 网页粘贴保留任务列表勾选状态、代码语言和常见内联样式。

## Documentation

- 11 份翻译 README 已同步最新功能表和 Typora/MarkText 对比表，保持 12 种语言内容一致。
