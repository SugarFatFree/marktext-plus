## 一、插件市场仍然能列出插件（BUG-421 真正改到的地方）

这条改的是发给 GitHub 的 user-agent，从写死的 `MarkTextPlus/1.6.0` 改成读
`AppConstants.appVersion`。它不影响界面，但它在**每一次插件市场搜索的请求头里**，
所以一旦拼错，市场会整个打不开——而单元测试用的是假的 HttpClient，看不到这个。

**怎么造**：设置 → 插件 → 打开插件市场（或侧边栏的插件面板），点刷新。

**该看到**：列出「AI Assistant」，版本显示 `v0.1.5`，标记为 Community/Unverified。

**要留意**：如果显示「请稍候再试」之类的限流提示，那是 GitHub 的未鉴权配额
（搜索 10 次/分钟、其余 60 次/小时），不是这条改动的问题——等一分钟再点。
真正的失败长相是**空列表而没有任何说明**，或者请求直接报错。
