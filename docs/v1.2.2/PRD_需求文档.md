## 详细需求

### FEAT-001 — 侧边栏目录持久化

| 字段 | 内容 |
|------|------|
| 实现日期 | 2026-05-01 |
| 优先级 | 高 |
| 难易度 | 简单 |
| 需求描述 | 左侧边栏"文件"中打开的目录，软件关闭后再打开时应继续存在，但不自动打开标签页 |
| 用户场景 | 1. 用户打开一个项目目录在侧边栏浏览文件<br>2. 关闭软件后重新打开，侧边栏应恢复之前的目录<br>3. 不应自动打开任何文件标签页 |
| 当前实现 | 侧边栏目录仅存在于内存中，关闭软件后丢失 |
| 实现方案 | 1. `AppConfig` 添加 `sideBarDirectory` 字段<br>2. 打开目录时（菜单栏、拖拽）保存路径到配置<br>3. 关闭目录时清空配置<br>4. 启动时从配置恢复目录（仅加载文件树，不打开标签页）<br>5. 恢复前检查目录是否仍然存在 |
| 涉及文件 | `lib/core/config/app_config.dart`<br>`lib/ui/screens/home_screen.dart`<br>`lib/ui/widgets/app_menu_bar.dart`<br>`lib/ui/widgets/side_bar.dart` |
| 验收标准 | 1. 打开目录后关闭软件，重新打开时侧边栏显示之前的目录<br>2. 不自动打开任何文件标签页<br>3. 如果目录已被删除，启动时不报错<br>4. 通过菜单栏"关闭文件夹"后，下次启动不再恢复<br>5. 拖拽文件夹到窗口也能持久化 |
