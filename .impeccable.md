## Design Context

### Users
MarkText Plus serves developers, writers, and technical users who edit Markdown locally on Windows, macOS, and Linux. They need fast startup, low resource use, reliable large-document handling, and direct keyboard/mouse workflows.

### Brand Personality
Lightweight, focused, practical.

### Aesthetic Direction
A compact native desktop tool: calm surfaces, clear hierarchy, dense but readable controls, restrained borders, and strong alignment. The plugin panel should feel like a dependable utility pane rather than a marketing page or a card gallery.

### Design Principles
- Keep the first useful action visible without explanatory clutter.
- Group related actions tightly and separate status from controls.
- Use fixed host slots for plugin contributions; never allow arbitrary layout injection.
- Make errors selectable and copyable.
- Preserve responsive behavior at narrow desktop widths and avoid startup work.
